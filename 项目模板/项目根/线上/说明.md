> 模板说明：线上代码，相当于 master。代码写进这里、被服务实时读到的那一刻就是上线，没有发布脚本。
> 在新流程里，运行版就是仓库主检出，停在发布分支；本目录只是代码所在位置之一。Promate 实例：`Promate产品中台/` 和 `promate-frontend/`，团队 .git；它仍走旧流程，未迁移。

# 线上

- 只有用户授权合入时，协调方在运行版执行 `bin/loop 合入 <批次.json>`；不推送远端。
- 合入前先留一份改前备份；批次分支由 `bin/loop 开工` 从发布分支拉出，不再每批同步。非 git 项目的兼容做法见 `项目模板/README.md` 的「兼容」一节。
- 服务实时读取的目录（Promate 是 `plugins/marketplace/`）不能留半成品。
- 有数据库迁移的，先备份数据库。
- 团队仓库的提交和推送另外要授权，和 loop 的本地合入是两件事。
