# 线上

- 只有协调方在合入时写这里，Pi 不碰。
- 合入：先三方对比（开工基线、线上现在、dev分支 改后），只搬这一批改的文件，不覆盖线上在开工之后的其他改动；动手前留一份改前备份。
- 服务实时读取的目录（Promate 是 `plugins/marketplace/`）不能留半成品。
- 有数据库迁移的，先备份数据库。
- 团队仓库的提交和推送另外要授权，和 loop 的外部基线无关。
