# 启动说明（<项目名>）

## 项目准备

在有本地 dev 的 Git 项目中，把示例配置另存本机 `.autoreview.json` 并替换占位符；本机配置和 localFiles 忽略、不提交。准备/恢复与非测试方法自检在 `.autoreview/methods/`，已有方法优先，失败如实停止，不绕过占位符或降低标准。开发方仍做受影响定向自检。

## 单次启动

写提示词和 version:1 卡，tasks 显式 prompt/scope，flow 按实际需要安排开发评审、测试、验收、提交、部署。旧 stages/workflow/steps、开工和独立后置验收已停用；不再每批建脚本或手工同步目录。

```bash
bin/loop 启动 docs/batches/示例批次-20261012/批次.json --dry-run --json

```

Pi 默认独立可输入窗口；明确后台使用 --launcher background，JSON 不改变选择。各任务保留原目录/会话/次数，未知进程或资源不重复派发。模板卡只安排开发评审，不自动提交/验收/部署；未安排不算通过。

发布须用户当次授权，沿 `bin/loop 合入 <卡>`，只 dev/推 origin/dev；只授权本地加 --仅本地。目标变化须整合并回原会话检查，用户脏内容/未知来源/消费者保护保留。部署仅在卡显式安排且发布/推送成功后执行。

临时单会话 `bin/loop 开发 pi|claude|codex --cwd <项目> <提示词>` 只做静态评审与原会话返修，不暗加测试/验收/提交。模型沿本机已核对配置，权限保留 auto/明确 deny，Ponytail 实际加载情况另核对，不擅自安装或改全局设置。
