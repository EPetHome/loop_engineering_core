> 模板说明：新卡使用隐藏受管 Git worktree。旧项目目录不自动迁移或删除，实际业务与发布授权以用户决定为准。

# 开发空间与发布边界

- 内核从本地已有 dev/base 冻结基线，按卡/任务登记隐藏空间、分支与原会话；不再用 workspaces 或仓库名推导可见目录。多任务独立空间并行，不共用目录串行开发。
- 正常单会话和用户未受管目录不自动提交。新卡仅程序提交 scope 内候选，保护用户暂存/未提交与本机文件，其他任务不能夹带。
- localFiles 和本机配置在启动前校验普通文件、忽略规则、Git/路径归属；不写穿链接或覆盖未知目标。原目录用户内容不被搬运/恢复。
- `bin/loop 合入 <卡>` 只按既定 dev 发布，默认推 origin/dev；--仅本地 记录未请求，重复调用不补推。目标前进形成新树须整合并重新检查。main 和任意目标分支不自动处理。
- 停止/放弃/发布后按登记释放；未知消费者、未保存成果或本机文件变更不删。历史 ref、证据、失败事实保留。

## 非 Git 兼容

原外部基线 GIT_DIR/GIT_WORK_TREE、手工同步目录不由本轮迁移。Pi 单会话在非 Git 目录仍可开发，但无法进行的评审会关闭并说明原因；新卡必须 Git。不再执行旧开工流程。
