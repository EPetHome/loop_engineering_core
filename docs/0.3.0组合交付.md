# 0.3.0 组合交付与验证边界

这是本次 Loop 内部开发的**组合源码候选**，不是安装/部署或用户已验收的运行版本。当前外层任务仍由旧引擎及旧接法驱动；本次仅修改提供的代码副本，没有替换/停止外层引擎、改原项目/基线、自动合并、发布或生产导出。

## 文件范围

| 目录/文件 | 内容 |
|---|---|
| engine/ | 0.3.0 调度、总收尾/正式导出、comparison/问题证据、活动用量、会话映射/锁/保护；原 CLI 与历史资料 |
| adapters/pi_member.py | 本地 Pi 前台 command/stdout，JSONL 双流投影、fresh 对照、精确 session / 实际工具 cwd / OS 旧路径保护 |
| run_loop.py | 组合前台入口、终态长日志可选简报、独立简报计量与失败降级；原返回码保留 |
| prompts/brief.md | 随交付的只读简报提示；不依赖项目外私有路径、不改权威结论、不预填收益 |
| docs/本机验证与会话对照.md | 同任务/模型/业务规则/预算两种完整启动步骤、结果入口与需核对/记录项目 |
| engine/tests/ 与 tests/ | 冻结旧测试加归属/锁/失败/旧回执反例、实际系统拒写及 A/B/C/D 组合测试 |
| acceptance/、reference/ | 只读冻结标准与本机 Pi 0.87.1 接法资料，没有修改 |

不能只拿 engine/ 而遗漏外部接法、run_loop 或提示/验证文档。engine/SHA256SUMS 仍采用原 checksums 功能维护，范围是 engine 内普通文件（含冻结旧资料，不含自身/缓存）；不伪称它覆盖 adapters/run_loop/prompts。版本以 engine/loop.py --version、README 首行、CHANGELOG 最前版本为同一 0.3.0；0.2.0 / 0.1.0 的正文与历史测试报告原样保留。

## 已做、未做分别说明

- **源码已实现并开发静态自检**：A 型可信总收尾，B 型旧正文/当前证据及显式解决，C 型流式活动/有覆盖的用量与计时，D 型默认 fresh、显式同开发业务返修复用。Pi 工具实际 cwd 不是仅变子进程 cwd：按只读安装源码摘录核实，持锁原子重绑自有 header.cwd，保留历史 entry/id；OS 沙箱实际继承到 bash/Python 并拒绝旧绝对路径/符号链接别名及 chmod 绕行。
- **第三轮离线自测已执行**：REG 实际发现 engine/tests 231、adapters 1、根目录 4、组合 tests 51（合计 287），冻结 U1/U2/U3/U4 分别 15/13/54/36 项通过；A/B/C/D 分别 5/1/1/2 个测试通过。累计新增 28 项会话反例、4 项组合测试包括三轮代码/两轮业务返修、显式问题解决、活动/用量、真实候选门禁、总收尾 PASS 与正式导出，不仅检查假成员自报。这些导出均在测试临时目录，与本次候选的正式外部导出/合并不同。
- **第二轮 D4 修复记录**：独立首轮静态评审指出合法 JSON 的 message=null 仍会被选择且重绑 header。已补上选择/交付可用性/重绑前三处共享的已知 v3 必需载荷与消息结构校验，损坏/未支持的形状明确 fresh 或拒绝重绑，保留旧会话字节；新增 6 项反例及有效格式/字节保留测试，不改冻结标准。第二轮离线自测通过，但不代表所有损坏映射已覆盖。
- **第三轮 D4 修复**：本次上下文的第二轮独立静态评审指出 ready 真值判断会把字符串 "false"、数字 1 当成复用资格，随后重写映射掩盖非法原值。本次新增 1 项从格式修复 ready=false 出发的反例（9 个子例），先在旧实现 REG 中实际重现 9 个失败；修复为选择旧会话前严格校验布尔类型，仅 true 可续接。缺字段或非布尔值明确 fresh，映射及事件记录损坏原因；检查适配器新会话可用、旧 header.cwd/历史/owner 字节未变。修复后 REG 全部通过，合法布尔 true 的两轮业务返修正例保留；发布最后检查的实际结果以最终开发交付 JSON 为准，不能用此前通过掩盖未覆盖缺陷。
- 开发过程曾发现 owned_path 把系统祖先 UID 当会话归属、只读评审探针误写当前代码的问题，以及新 infra 测试未显式开启 demo 中默认 0 的重试额度；均修正后再检查，不用降低冻结断言或当前通过抹掉先前失败。发布最后检查使用冻结 acceptance/release.py 复用旧 checksums/release 行为（目标版本 0.3.0）；本次最终检查的实际退出结果在开发交付 JSON，外层随后独立记录门禁证据，不由本页自称最终验收。
- **静态评审边界**：上面是开发方代码/参数/文案自检。独立 reviewer 对当前组合候选的静态评审尚待外层执行；本页不冒充该评审，也不把旧单元评审或开发自评当最终结论。
- **未验证**：新功能真实 Pi/Codex CLI、账号/模型权限、真实持久会话接法、模型/简报语义质量、真实费用/时间节省、业务收益、生产环境与人工验收。Pi --offline 仍可进行用户授权的模型调用，provider cost=0 / message 数 / 假桩通过不证明真实节省。人工收益对照需用户按文档另行启动，没有预填节省比例。

默认 fresh；reviewer、格式修复与失败重试不续接原会话。reuse_repairs 只支持交付内本地 Pi command/stdout 和有效 macOS sandbox-exec；不支持接法、锁竞争或保护不可用明确拒绝，缺失/坏/归属或配置不符不猜测。只保护相应数据路径，不提供全机器/原项目/网络隔离。详见 [会话契约](../engine/docs/15-开发会话复用.md) 与 [组合入口](组合入口与观测.md)。
