# 组合入口与观测（0.3.0）

项目根目录同时包含 engine/、adapters/、run_loop.py 和 prompts/。以下是循环之外拍板人的使用说明，不是循环内部成员启动真实任务的授权。

- 原入口保持 `python3 run_loop.py PLAN --root DATA_DIR`，先运行原引擎，只有完整终态、长日志且未取消才追加辅助简报。返回原 supervise 退出码；简报失败、空正文或超时均保留原始结果，不重新开发。
- `prompts/brief.md` 随本项目交付，不再读取工作站私有提示词路径。简报型号仍为 opencode-go/deepseek-v4.1-flash / xhigh，只读工具与显式权限扩展不变，明确 --no-session。
- 自定义 command 的 argv 可继续使用 `{python}`、本交付的 adapters/pi_member.py、原 `--model` / `--thinking` / `--tools`，output 必须 stdout。需要覆写程序时使用既有 LOOP_PI_BIN；只有拍板人确认后才能指向真实 Pi。本次测试只指向本地确定性假程序。
- LOOP_CONTEXT 决定当前工作区、限制和时限；独立调用可传 `--workspace DIR` 与只缩短时限的 `--timeout-seconds`。标准输入仍是原提示；最终 stdout 只交付完整合法 assistant 文本中的 JSON，原始事件与诊断不混入交付。
- 成员工作区有 pi-events.jsonl、pi-stderr.log、activity.json、usage.json。进程尚未退出即可看 last_event_at；没有事件只能显示 unknown，工具阶段按 toolCallId 关联。心跳读取投影可从引擎 status / status --json 看到，终态封存并汇总到原结果。
- tokens 分维汇总 message_end；缺失为 null，coverage 的 observed_total 是小计。assistant_messages / member_invocations 不是 HTTP 次数；api_requests 与实际 cost 保持 null，provider cost=0 不表示免费。重试、compaction 的隐藏/摘要用量和重复理解成本未知。
- `交付结果.md` 与 `delivery-overview.json` 分开列引擎和额外简报次数、耗时及用量。引擎端到端墙钟包含门禁/I/O/等待；runner elapsed_seconds 是 guardian monotonic 范围，wall_elapsed_seconds 是同范围墙钟，差 > 2 秒有说明，不直接归因模型。原 manifest 的终态、预算和原始结果不为简报统计改写。
- 入口只链接真实存在的对应文件。模型简报必须区分真实成员参与、尚未验证的新接法、人工未验收；提示正确不保证模型每次都正确，原 manifest、result 与证据才是判断依据。

限制：原始 stdout + stderr 共用 limits.max_log_bytes，单行内存缓冲同样有界；持续活动不延长硬超时。取消/非零退出/超限/未 settled/新一轮未完成不能交付半段或旧回复。所有工具生命周期事件都会使旧交付候选失效，缺失/非法/未匹配 toolCallId 也不例外；即使进程退出 0，仅重复 settled 或工具 end 也不能放行旧 JSON。后续新的完整合法 assistant 响应及 settled 可恢复交付，历史工具关联缺口仍使 tool_calls=null。无类型事件的旧文本接法仅在成功退出后兼容，所有用量未知，不是 JSONL 故障时的回退。

详细字段、文件、失败路径与 CLI 约定见 [引擎观测说明](../engine/docs/14-活动用量与简报边界.md)。真实 CLI/账号、新功能实接、模型简报语义质量与时间/费用节省收益未验证；人工业务验收未进行。0.3.0 默认 fresh 保留；显式 developer_session=reuse_repairs 只支持交付内本地 Pi command/stdout，同 run/unit/developer 连续业务返修共享自有精确会话路径，持锁原子重绑实际工具 cwd 并实质保护旧 checkout/冻结树，评审/格式修复和失败重试新会话。不支持的接法/平台明确拒绝，损坏/归属或配置不符不猜续接。详见 [会话契约](../engine/docs/15-开发会话复用.md)、[用户真实对照](本机验证与会话对照.md) 及 [组合交付](0.3.0组合交付.md)。新实现未部署，当前外层仍由旧引擎/接法驱动；人工决定验收合并，不自动合并。
