### 6.1 合并

```bash
cd /Users/Admin/Desktop/loop
for n in review time cost resume; do
  git apply --3way --whitespace=nowarn /Users/Admin/loop-wt/$n.patch || echo "CONFLICT in $n"
  # 有冲突：手工解决、去掉冲突标记，再跑快速套件，然后才合下一个
```
