# 单一入口：规则不进项目，结果直接看

## 目标

两个问题：

- **规则复制进项目**：【块 1】要求复制到项目的 `.autoreview/CONVENTIONS.md`，只能手动跑 `setup-acceptance.ts` 更新。本机接入项目全部落后（Promate v5、personal agent v6、产品智能体 v6，最新 v7），提醒只在跑完的总结里出现。而开发方的约定本来就由 Loop 运行时注入（`core.ts` 的 `conventionText`），起草指路也已按需注入（`production-loop.ts`），副本是多余的。
- **要求协调方回写**：【块 1】「收尾回写」、`ledger.ts` 的待回写提醒、交付总表「已回写原单」勾选，让结果被抄成第二份。用户定：Loop 干完，直接看 Loop 的总结。
