# Promate WorkBuddy 插件

本批 MCP 补齐源码；发布版本与正式装配由最终集成角色统一处理，不覆盖已验收的 0.2.15。

## 安装与本地配置

支持目标：macOS WorkBuddy 5.6.2 已核构建，使用 WorkBuddy 自带 Node，无需另装运行时。其它版本遇到未核条件明确停止；开发入口 localhost 只适合同机。

1. 从 Promate「技能 · 工具」点击「接入 WorkBuddy」，确认启动固定先导。程序核对当前用户/profile、目标版本与摘要，通过宿主原生程序安装/升级和启用，只管理 Promate。
2. 程序自动登记市场、安装并启用插件。若提示已写入、等待重启，请在其他任务结束后自行完全退出并重新打开 WorkBuddy 一次；不要重发安装命令。重启后进入普通会话，SessionStart 钩子接续一次性请求并打开本机私密页；不手动输入市场地址或配置命令。钩子运行、私密页可达、桌面 MCP 代理版本与平台身份连接须分别确认。
3. 在私密页输入 Key，保存后自动只读检查连接。原有 Key 可先检查；401、服务故障或结果未确认时，同页可继续输入、更换或重试（Key是否保存与身份是否成功分别显示）。只有检查成功才结束配置；空项目列表也算连接成功。

日常使用中业务调用收到平台401，代理只在聊天工具结果提供当前本机「配置 Key」链接，不自动弹页；同源有效链接复用，用户自己点击并在私密页更换Key，随后同一代理会重读配置。401也可能与账号状态有关；保存Key不等于认证成功，失败的业务操作（尤其写操作）不会自动重放。链接由独立短期进程持有，原代理或会话退出后仍可在本机继续配置；成功／取消／到期／换来源后失效，期限不超过首次创建后的五分钟。用户主动请求或链接失效时才使用无参数的 `configure_key`。首次接入的SessionStart自动开页不变。

私密链接仅本机有效、五分钟过期；每次提交使用一次性 nonce，失败可在原期限内换 Key 或重试，成功／取消后页面失效。**不要在普通聊天或工具参数发送 Key**。取消、失效或打开失败时可从网页重新发起受控接入；不会清除原有配置。实现/宿主/业务的实际验证范围以项目交付记录为准。

配置复用 `~/.promate/config.json` 的 `url`、`key` 字段，保留其它字段。目录 700、配置 600。`PROMATE_HOME` 可指定隔离目录，`PROMATE_CONFIG` 优先。地址允许 HTTP(S) 的平台根路径或 `/api/mcp`；拒绝凭据、查询参数、片段。`keyOrigin` 记录凭据绑定来源，换来源保留旧 Key 但停止发送，须用户重新为该来源配置 Key；HTTP 重定向不携带凭据跟随。已有仅 key 的配置按本机历史来源保护，不将其静默发送给新远端。

代理每次调用重读配置。无地址的 localhost 回退仅供本机开发；远端安装必须先写 url，错误配置不回退 localhost。

`configure.mjs` 仅供研发隔离检查，不是用户安装或失败兜底流程。先导使用原生 `codebuddy plugin` 程序，不手改宿主登记或覆盖缓存；一次性公开接入标记绑定用户/profile/版本/地址，仅由经安装路径、profile 和市场来源校验的 SessionStart 钩子消费；旧代理不自动开页。`configure_key` 只给出插件本机页面，不接收 Key 参数；页面 POST 经 loopback Host/Origin、随机且每次提交更新的 nonce、固定有效期、提交互斥和目标地址快照校验后复用原子保存；临时页面子进程最多存活五分钟，不是常驻服务。Key 不进链接、模型、工具参数或确认文案；MCP 协议版本不变；新版 15 个服务端工具＋3 个本地资源工具，另保留本地 configure_key。旧插件按未声明新版能力的兼容目录取工具；能力声明不是权限证明。

## 写操作与结果

`mark_done`、`mark_delivered`、`add_artifact`、`upload_skill`、`update_artifact`、`remove_artifact`、`retry_writeback`、`upload_skill_version`、`uninstall_resource`，以及旧别名 `set_stage`，在所有 WorkBuddy 权限模式统一对话确认，不依赖 `ask` 弹框。首次 deny 展示实际目标／参数；用户独立回复「确认/确定」，同会话、工具、参数、平台／profile／凭据且未过期才放行一次。上传使用绝对 `filePath`，确认显示摘要和大小，代理读取一次并核验后发送同份 bytes；文件变化须重新确认，不把内容交给模型。回写重试经 `get_requirement outboxId` 查询并绑定具体不可变任务目标，不改成最近任务。卸载绑定实际归属及文件摘要。取消、其它回复、改参、换来源／profile、重放、超过 10 分钟、缺会话、坏状态或锁冲突均不复用确认。标题经 MCP 查询，取不到也不能直接放行。

取消保护（自 0.2.4 起保留）：`route` 在抢会话锁及 Key/探针短路之前，向 `state/<session>.json.messages` 追加随机消息 ID（不保存正文或 Key）。追加顺序决定代次，不用旧快照覆盖当前标记；这不是后台队列。`pendingConfirm.messageId` 由 `confirm` 建立请求时记录、`route` 在独立确认时更新，只有相邻且仍最新的消息可确认该请求。`confirm` 在锁内消费前与输出 allow 前均检查最新代次；`mark` 只写原状态文件，写回旧快照也不能恢复授权。代次记录随 24 小时过期清理；损坏/不可读时拒绝放行，旧版没有代次的确认须重新发起。

锁冲突时本条用户消息不建立新授权，但旧的未消费确认已失效；会话状态异常会明确报错，不静默声称取消成功。取消仅撤销待消费授权，**不承诺撤回已获放行或已提交的业务写入**。

- 所有角色只能访问本人绑定的启用项目。完成允许负责人或绑定超管；交付研发仍限负责人/本需求未删除产出物登记人，超管无额外例外。
- 状态回写 `PENDING/PUBLISHED` 仅为已提交/已发送；`SUCCESS` 才是服务端确认成功（无 outbox 的 noop 不代表新写入）。`FAILED/SUPERSEDED` 按返回信息说明；超时或连接中断不代表没写入，先查询，不自动重放。
- 产出物按需求＋规范化链接幂等；修改／删除沿用平台权限，只做可撤销删除。上传及新版本经既有审核，不自审、不自动上架；审核状态用 my_skills。invoke_skill 已下线，所有路径拒绝调用。
- 无 Key、401、断网/超时和错误配置时，本地工具目录只保证插件可发现；业务调用明确失败，不假装平台已连通。
- 停用插件后自身 hook/MCP 不再生效；不能阻止宿主其他工具直连飞书，也不是通用安全沙箱。

## 本机安装与加载统计

- `get_skill` 只读正式说明，不下载、不计获取。成员主动要求才用 install_resource 安装／升级正式自建技能；完整名称重名返回候选，外部只返回链接。
- 归属、每文件 SHA-256、历史加载标记、事务及回报队列保存在 `~/.promate/resources/`，绑定 MCP 地址、WorkBuddy profile 和实际技能目录。目录默认 `<profile>/skills/<SKILL name>`（正常 WorkBuddy 为 `~/.workbuddy/skills`）。包 SHA-256 先核验；zip 拒绝穿越、绝对路径、链接、重复路径和 >50MB 解压；≤10MB 的 .md／单技能 zip 支持。
- 同版未改内容直接复用；未知同名目录／被替换目录拒绝。修改先备份；新版改 name 先装新目录，再移动记录里的旧目录；卸载先整目录移到备份并返回位置。macOS 内核锁串行化同技能目录中的资源，包括两个代理／不同资源同名；事务中断先恢复，旧版与备份不丢。
- 安装／升级／卸载及失败由 MCP 程序回报；断网本机暂存，下次资源查询／操作补报，只补事件、不重装。原平台／profile 必须一致；更换 Key 后先核对服务端稳定成员身份，相同原成员可补旧回报，不同成员或原身份未知则暂停，不把旧事件归到新身份。
- 本机 SKILL.md 附不含秘密的随机注释，绑定实际正式下载版；Skill PostToolUse 按实际返回正文标记及受管目录记录加载版本，旧标记记旧版，不以当前目录最新版猜旧会话。PreToolUse 只绑定来源／身份指纹，不保存 Key；异常也留痕，没有实际版本时按 VERSION_UNKNOWN 记录归因失败，不计成功加载。**加载不等于业务完成**，非平台技能不上报；不发送对话或文件正文。
- 原装宿主隔离检查不能代表用户桌面。安装后保守提示新开对话，当前／旧对话不保证生效；钩子版本不是 MCP 代理版本。旧平台缺工具／程序接口明确提示尚未升级，不退回旧 get_skill 解包。

## 市场、版本与源码

市场根目录是 `plugins/marketplace/`，zip 首层必须为 `.codebuddy-plugin/` 和 `plugins/`。服务复用：
- `/api/skills/plugins/marketplace.zip`：公开下载，ETag/Last-Modified/304。
- `/api/skills/plugins/latest`：版本及下载地址；可信部署配置 `promate.plugins.public-base-url` 优先，未配置返回相对路径，客户端按公开平台入口解析。不从任意 Host/Forwarded 请求头推可信地址。

- `/api/skills/plugins/connect`：公开先导元数据；`pilot-<sha256>.mjs` 和 `marketplace-<sha256>.zip` 为固定内容发布地址。

发版同步三处插件版本，MCP `serverInfo.version=0.1.0` 独立。先导将 Promate 市场指向持久的摘要地址；再次接入才按平台元数据升级，不承诺后台自动更新。旧发布物保留，禁止把市场登记到随后删除的临时文件。

`mcp/tools.json.tools` 对应 15 个 Java 服务工具；上传将 fileName/contentBase64 转为模型 filePath，其余定义及握手说明逐字段一致。localTools 单列 3 个本地资源工具；configure_key 由代理追加。目录一致性测试分层保留，旧目录单独覆盖且不恢复 Demo。对应检查：
```sh
node --test plugins/tests/
```
测试只使用虚构 Key、临时 `PROMATE_HOME` 与 loopback stub，`PROMATE_SKILLS_DIR` 隔离 guard 技能目录，不调用真实平台。本地脚本测试不替代 WorkBuddy 桌面产品验收。
