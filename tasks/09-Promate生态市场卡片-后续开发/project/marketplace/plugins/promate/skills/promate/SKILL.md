Promate 是公司内部平台。项目用 my_projects；list_requirements 可不填项目跨可见项目按标题／编号搜索；需求详情、产出物和具体回写任务用 get_requirement；提醒用 my_alerts。飞书数据按固定间隔同步，非实时。完成用 mark_done，交付研发用 mark_delivered，各只写自己的字段；受理或重试不代表飞书已更新，超时先查询，不自动重放。失败任务以 outboxId 查询具体目标，确认后 retry_writeback，不能改为最近任务。

产出物用 add_artifact 登记、update_artifact 修改、remove_artifact 可撤销删除，沿用平台权限。九类写操作须展示实际目标和全部参数，等用户独立回复「确认」；改参重新确认，取消不执行。不得把“完成了”当确认或以宿主权限模式跳过。标题查询失败不绕过 MCP 或直接拿 Key 调业务接口。

list_skills 搜索正式团队技能并显示本机版本／更新；get_skill 仅看正式说明，不下载、不计获取。只有成员主动要求才用本地 install_resource 按 ID 或完整名称安装／升级；同名先选 ID，不猜；外部仅返回来源链接，不复制安装提示。my_installed 查此平台／profile 的归属、版本、更新与回报状态，断网最新版本未知。卸载用 uninstall_resource，确认实际技能、目录和文件摘要，先备份并告知位置，不动未知本机目录。

上传用 upload_skill，本人技能新版本用 upload_skill_version，审核用 my_skills。模型只传实际本机 .md／.zip 的绝对 filePath（≤10MB）；代理在内部读取、摘要核验并转换，不把 Base64、文件正文或凭据放进参数／对话。确认显示路径、字节数和 SHA-256；改文件内容重新确认。扫描／审核通过前不自动上架，正式版继续保留。

安装后提示新开对话加载；当前／旧对话不保证生效，不能因磁盘升级说旧对话已经换版。平台 Skill 钩子根据实际加载标记上报真实版本，未知版本明确归因失败；这只表示说明加载，绝不表示业务完成。回报断网暂存，只补回报、不重装、不重放业务，旧来源／Key／profile 队列不串报。不要调用已下线的 invoke_skill；平台未升级或程序接口缺失时如实提示，不退回旧 get_skill 包内容路径。钩子加载版本不等于 MCP 代理加载版本。

若首次未配置 Key，或成员明确说「配置／更换 Promate Key」：请调用无参数的 Promate MCP `configure_key`（宿主一般显示为 `mcp__promate__configure_key`）。它与本地配置 hook 共享同一个幂等恢复闸门，只创建或复用真实的 loopback 私密配置页。若会话上下文已有配置页地址，不重复调用，不再承诺“已经自动打开”；提醒用户检查已有页面即可。代理实际返回 URL 时按返回内容原样给出带令牌地址供手动点击，不读本地会话文件、不编造旧地址、不让成员在对话粘贴 Key。配置 hook 提示该场景无需旧 MCP guard 时，不手动调用该 guard；当前钩子加载不证明 MCP 代理已同步更新。401 的已有恢复页面不重复创建或自动打开；403 属于权限不足，不能说成 Key 失效或重新索取 Key；网络／业务报错同样不能触发配置页。Key 提交后私密页由代理 initialize/验证探测核验；用户关页、换回普通消息或重复请求时，只按实际页面状态继续，不用复制配置话术刷屏。Key 或密码不得进入模型工具参数／正文、终端命令、curl、配置文件读写、日志、截图、网页 DOM 导出或取证截图；不得让模型替成员粘贴、代填、读取或重述凭据。
