## 门禁脚本 `scene_gate.py`

指纹（sha256）：`99ed70f56a11ec9b50712b8580b291364e674fd99ba424554a89b34e158f3ebb`。它放在 `source` 之外，不受引擎的完整性保护，验收时要核这个指纹。

做的事：把候选 `team` 抄到门禁工作目录并改写路径 → 搭临时 `DSH_HOME`（profile 改路径，凭据用符号链接、跑完即删）→ 新建运行目录，用原项目的 dsh 真跑 → 程序判定 → 解压会话、写证据包。

| 程序判定的项 | 不通过时的原因标记 |
|---|---|
| 场景进程在时限内结束（默认 1200 秒） | `scene-timeout` |
| 退出码为 0 | `scene-exit-<退出码>` |
| 至少有一个可读的原始会话 | `no-session` |
| 运行记录里没有出现原项目的团队目录 | `used-original-team` |
| 运行记录里出现了临时团队目录；候选团队规则里改过的行都出现在会话里 | `candidate-rules-not-loaded` |
| 有正式保存的成果 | `not-saved` |
| 保存的文件与保存回执指纹一致 | `sha-mismatch` |
| 每份保存的成果都有被接受的检查结论 | `check-not-completed:<json-invalid / quote-not-verbatim / snapshot-mismatch / other / no-accepted-conclusion>` |

证据包在 `<门禁工作目录>/evidence/`：`摘要.json`（判定、每次草稿提交的结果、候选改过的行有几行出现在会话里、各文件位置），`会话/` 下每个会话一份原始 `.jsonl` 和一份人读 `.md`。运行目录在 `<门禁工作目录>/stage/run/`。

单独运行（不经过引擎；会真调业务模型）：

```bash
/opt/homebrew/bin/python3.12 "/Users/Admin/Desktop/Loop/tasks/05-真实项目场景小试/scene_gate.py" \
  --code <一份 team 的副本> --workspace <一个不存在的空目录> --scene S0
```

`S0` 是冒烟（不调工具）；`C06` 是正式场景。
