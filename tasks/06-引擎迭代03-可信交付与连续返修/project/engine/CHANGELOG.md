# 更新记录

## 0.2.0

- 版本号、README 和本变更记录统一更新到 0.2.0；新增 checksums 核对与 --write 重新生成包内 SHA256SUMS，覆盖普通文件、缓存排除、差异报告和离线回归测试；记录每次合并迭代的版本与指纹维护规则，保留 0.1.0 历史验收记录原文。

- 修复取证引用中间路径含循环符号链接时绕过格式修复流程的问题：先检查相对路径并逐层拒绝链接，再解析路径；新增自循环、互循环链接及错误后合法重交的离线回归测试。

- 单元新增 reviewer_exec 布尔开关（默认 false）：评审方可执行只读命令取证，独立取证目录通过 scratch_path/LOOP_SCRATCH 提供，允许 scratch: 普通文件引用并检查总大小；格式修复保留取证内容，接受的引用只读封存、记录指纹供 audit 核对，未引用文件不删除。Pi 评审开启时增加 bash/write，Codex 与自定义命令不改；补充安全边界、接入说明及离线回归测试。

- 修复重跑副本目录与合法门禁 ID（如 G1-a002）碰撞：后续执行使用独立 gate-reruns 层级，保留首次目录与日志位置；增加两种门禁顺序的离线回归测试。

- 门禁新增可选 max_reruns（0–5，默认 0）：仅非 0 退出限次重跑；逐次保留日志、失败原因和证据，跨门禁同因两次停止，返修后全部重新执行；结果醒目标注重跑通过与重复原因，新增 gate_reruns 计数、离线回归测试及规则/验收文档。

- 修复目录枚举错误被静默忽略的问题：纳入范围的目录不可读时，原项目收尾核对记录失败原因并以 BLOCKED 生成结果；增加实际 scandir 层的空目录、非空目录和排除目录回归测试。

- 正常收尾时重新核对本次原始输入来源；原项目差异通过 source_drift 列出并使总结果为 BLOCKED（退出码 3），扫描失败保留原因并生成结果，不改写单元结论和证据；补充边界说明与离线回归测试。

- 明确成员提示和接入文档中的证据引用写法及开发方限制，保持严格证据校验；交付格式修复额度改为同一单元内按开发方、评审方分别累计，保留总次数并新增按角色统计和离线回归测试。
