# 01 愿景与原则

## 1. 用户的愿景

用户 2026-10-01 的原话：

> 我希望是整个开发过程是全自动的，然后我的头脑风暴什么都是独立在循环之外，不干扰循环，我只负责启动与验收，中间的开发、代码自测这些串行运行全部在循环内部。成我们自己的一套定制的 Loop Engineering。

> 我的愿景是，我们讨论好哪些可以并行，哪些要串行，然后制定好规则，这个规则也包含了之前所提到的那些边界、验收标准什么的，等等的一些约束。我在这个过程中只要负责启动就行了，剩下的就是我和你一起验收。

> 我的本意是建立一个循环，有开发、有检查，制定标准控制完成标准、验收、什么时候停等情况，循环停止 == 给结果。

拆开来是五点：

1. **全自动**：从启动到停止，中间不需要人。
2. **里外分开**：头脑风暴、定需求、定方案都在循环之外，不干扰循环。
3. **用户只做两件事**：启动、验收。
4. **标准控制循环**：什么叫完成、怎么验收、什么时候停，都由事先定好的标准决定。
5. **停止就是给结果**：循环一停，结果就在那里。

## 2. 循环之外和循环之内

```text
┌────────── 循环之外：拍板人（用户 + 陪用户讨论的模型）──────────┐
│  头脑风暴 → 需求 → 方案 → 规则 + 提示词 + 启动指令              │
│                                   （用户启动一次）              │
│  全部停下后：看结果 → 验收 → 更新基线                           │
└───────────────────────────────────────────────────────────────┘

┌────────── 循环之内 ──────────────────────────────────────────┐
│  开发、自测、评审、交接、计数、判停、交结果                    │
│  全部自动，文档全部落在工作区                                  │
└───────────────────────────────────────────────────────────────┘
```

| | 循环之外 | 循环之内 |
|---|---|---|
| 谁 | 拍板人：用户，和陪用户讨论的模型 | 成员：开发方、评审方；以及调度和编排程序 |
| 做什么 | 想清楚要什么；写规则；准备提示词和启动指令；启动；验收；更新基线 | 按规则开发、自测、评审；不达标就修；停止时交结果 |
| 不做什么 | 运行期间不介入、不守着、不轮询 | 不改规则；不碰基线；不替拍板人做决定 |
| 责任 | 规则写得对不对、结果认不认 | 按规则把事做完，如实交结果 |

用户对陪他讨论的模型说过：「你把自己想成是我就行了，我和你是位于循环之外。」所以这个模型不是循环里的角色，不在运行期间承担任何工作。

## 3. 四条不能松的底线

这四条和任务类型无关，任何单元都必须满足。

| # | 底线 | 不守会怎样（实战里发生过的） |
|---|---|---|
| 1 | 完成标准必须能逐条检查 | 标准只有一句话，跑完才发现标准自己打架 |
| 2 | 评审方和开发方不是同一方 | 自己查自己，查不出自己的盲区 |
| 3 | 必须有停止条件，包括上限 | 没有上限就可能一直转 |
| 4 | 任何停止都要交结果；没有结果的停止算故障 | 循环中途停了却什么都没交，空转六个半小时没人知道 |

## 4. 设计原则

| 原则 | 说明 |
|---|---|
| 骨架要小 | 循环本身只有「开发 → 评审 → 达标就停，不达标再来」。别的做法都是按任务选的，不进骨架 |
| 标准是主角 | 流程不变，变的是标准。每个任务靠自己的标准来控制循环 |
| 简单和复杂是同一套 | 小问题用一个单元；复杂任务是多个同样的单元按并行、串行排起来 |
| 成员不能改标准 | 遇到规则没说清的事，成员不能自己定，因为那等于改标准 |
| 不靠中途拍板 | 规则没说清的，从严处理、记下来、继续做其余的，留到验收时一起处理 |
| 能用程序卡住的就不用文字 | 文字规则最容易被忽略；程序门禁和逐条填表才可靠 |
| 单元要小 | 单元越小，出问题时白跑的代价越低 |

## 5. 这套办法不是什么

- 不是一套固定的流程制度。第一稿曾写成「五步流程加十四栏任务卡」，用户指出写太死，已废弃。
- 不替拍板人验收。循环给的是结果，认不认由拍板人决定。
- 不更新基线。基线在循环之外。
- 不保证规则写得对。规则有缺口时，循环会如实暴露出来，但不会自己补。
