### 迭代03 / u7-evidence

- 内层响应可选 issue_resolutions，旧响应继续合法；仅评审可用当前候选证据显式解决已知 ID。未知/重复 ID、开发越权、无证据或旧证据按协议拒收；关联门禁 FAIL / UNKNOWN、缺失或旧绑定时解决不生效且记录依据。resolution 绑定本轮 candidate_hash，code / gate / 允许的 scratch 引用保存当前证据索引，仅解决引用的取证文件也封存。

### 迭代03 / u6-finalization

- 总结果新增 finalization（PASS / FAIL / UNKNOWN），绑定本次规则、输入及各单元当前候选指纹；冻结记录、输入快照、全部当前候选和原项目核对完成才通过，与总状态同一次原子提交。
- 原项目变化、扫描或完整性失败使总收尾 FAIL、总体 BLOCKED，不改已提交单元成果；丢失总收尾提交的恢复为 UNKNOWN / BLOCKED，即使所有单元已 PASSED，也不重新调用成员或猜测完成。
- 正式 export 同时要求所选单元 PASSED、audit 完整、有效绑定且 PASS 的总收尾；异常、未知和旧记录缺少 finalization 均拒绝并提示候选位置。独立单元业务 NOT_MET 不阻止已通过成果显式导出，目标仍拒绝覆盖。
- 结果 Markdown / HTML、status / recover 明示收尾状态，空 source_drift 不再代替完成证明；新增冻结证据丢失、输入/候选异常、最终原子提交失败和终态只重建视图等离线反例回归。
- 本单元只验证离线协议桩与故障注入；真实 Pi/Codex CLI、账号、模型质量及会话复用的节省收益均未验证，默认新会话不变。版本发布与组合交付由后续集成单元处理。

- 单元新增 reviewer_exec 布尔开关（默认 false）：评审方可执行只读命令取证，独立取证目录通过 scratch_path/LOOP_SCRATCH 提供，允许 scratch: 普通文件引用并检查总大小；格式修复保留取证内容，接受的引用只读封存、记录指纹供 audit 核对，未引用文件不删除。Pi 评审开启时增加 bash/write，Codex 与自定义命令不改；补充安全边界、接入说明及离线回归测试。

- 修复重跑副本目录与合法门禁 ID（如 G1-a002）碰撞：后续执行使用独立 gate-reruns 层级，保留首次目录与日志位置；增加两种门禁顺序的离线回归测试。

- 门禁新增可选 max_reruns（0–5，默认 0）：仅非 0 退出限次重跑；逐次保留日志、失败原因和证据，跨门禁同因两次停止，返修后全部重新执行；结果醒目标注重跑通过与重复原因，新增 gate_reruns 计数、离线回归测试及规则/验收文档。

- 修复目录枚举错误被静默忽略的问题：纳入范围的目录不可读时，原项目收尾核对记录失败原因并以 BLOCKED 生成结果；增加实际 scandir 层的空目录、非空目录和排除目录回归测试。

- 正常收尾时重新核对本次原始输入来源；原项目差异通过 source_drift 列出并使总结果为 BLOCKED（退出码 3），扫描失败保留原因并生成结果，不改写单元结论和证据；补充边界说明与离线回归测试。

- 明确成员提示和接入文档中的证据引用写法及开发方限制，保持严格证据校验；交付格式修复额度改为同一单元内按开发方、评审方分别累计，保留总次数并新增按角色统计和离线回归测试。
